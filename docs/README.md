# Documentation

Website structure, user journeys, content strategy, and decision history.

**Key files:**
- `SITEMAP.md` — information architecture and page hierarchy.
- `USER_JOURNEYS.md` — how different audiences navigate and experience the site.
- `CONTENT_STRATEGY.md` — writing style, tone, and messaging approach.
- `DOCUMENTATION_STYLE.md` — standards for documenting features and APIs.
- `DECISIONS.md` — architectural decisions and their rationale (DDR — Design Decision Record).
- `ROADMAP.md` — planned phases and future direction.
- `CHANGELOG.md` — historical log of all changes.

**Before making a significant design choice:**
Add an entry to `DECISIONS.md` explaining the context, decision, alternatives, trade-offs, and result.

**When writing any content:**
Follow the tone and style defined in `CONTENT_STRATEGY.md`.
