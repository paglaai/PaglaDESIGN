# Brand

Brand identity, logos, typography, colors, and usage guidelines.

**Key files:**
- `BRAND.md` — canonical brand identity, including the Pagla Face mark, typography choice, color principles, and voice.
- `BRANDKIT.md` — brand kit reference (may consolidate with BRAND.md in future).

**Before using the PaglaAI mark or creating marketing materials:**
Consult `BRAND.md` for usage guidelines, clearspace, sizing, and tone.

**The brand is carried by:**
- The Pagla Face (mark)
- Neutral typography and generous whitespace
- Editorial restraint
- Consistency across all products

**Do not:**
- Apply color as the primary identity
- Use decorative versions of the mark
- Add drop shadows or effects
- Deviate from the approved palette
