# Components

Reusable UI components and the component language.

**Key files:**
- `COMPONENTS.md` — component anatomy, shared states, and design patterns.
- `COMPONENT_LIBRARY.md` — registry of all active components and their lifecycle.

**Before adding a new component:**
1. Check if an existing component can solve the problem.
2. Document the design in `COMPONENTS.md`.
3. Register it in `COMPONENT_LIBRARY.md`.
4. Ensure it passes the quality gate: accessible, token-driven, motion-correct, documented.

**A component that is used only once is not a component.**
