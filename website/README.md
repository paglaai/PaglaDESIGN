# Website

Website content, layouts, and public-facing materials.

**Purpose:**
Home for website HTML, CSS, and copy that represents the PaglaAI brand publicly.

**Structure:**
- `index.html` — homepage
- `style/` — website-specific stylesheets (derived from `css/` and design tokens)
- `content/` — markdown or HTML files for pages
- `assets/` — images, icons, downloads

**Before designing the website:**
- Review `brand/BRAND.md` for identity and voice
- Review `design-system/DESIGN_TOKENS.md` for colors, spacing, typography
- Reference `docs/SITEMAP.md` for page structure
- Reference `docs/CONTENT_STRATEGY.md` for tone and messaging

**The website is the first impression of PaglaAI.**
Quality, clarity, and consistency are non-negotiable.
