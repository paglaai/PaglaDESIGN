## D-020 · Relocate and Rewrite the Agent Manual

| Field | Value |
|-------|-------|
| **Status** | Adopted |
| **Date** | 2026-08-07 |
| **Canonical record** | `../../governance/DECISIONS.md` → D-020 |

### Context

A previous manual (v1.0.0, "PaglaOS × Stitch × PaglaDESIGN") lived in
`PaglaAI.space/Agent-Manual/` and **defined** the system: it carried its own
token values, components, a 12-column grid, skills, and MCP tools. Those
values and components disagreed with the canonical authority (PaglaDESIGN):
invented palette (`#FF3E00`, `#0A0A0A`, gradients), invented fonts
(Inter, JetBrains Mono, Plus Jakarta Sans), invented components (Badge,
Avatar, Dropdown, Tooltip), a fabricated lint CLI, and fabricated MCP tools.

### Decision

- Move the manual into the authority: `../../.ai/agent-manual/`.
- Rewrite it as **operating procedure only** — it inherits tokens,
  components, templates, and tools from the authority instead of redefining
  them.
- STITCH stays documented as an **external, optional** generator.
- The prompt formula, lint severity model, build playbook, and anti-patterns
  are kept as the manual's genuine value-add.
- The manual DOCX is regenerated by a fixed `build_docx.py` with canonical
  monochrome styling; duplicate DOCX artifacts were removed.

### Result

The manual and the authority live in one repository. The manual can no longer
drift from the system because it does not carry the system's values.
