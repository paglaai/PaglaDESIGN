# TYPOGRAPHY

> Typography is the primary interface of the PaglaAI ecosystem.

---

# Philosophy

Typography is the foundation of the PaglaAI visual language.

Rather than relying on decoration, excessive color, or visual effects, PaglaAI communicates hierarchy through carefully structured typography.

Good typography should make interfaces feel calm, readable, and trustworthy.

The reader's attention should always remain on the content—not the design itself.

---

# Design Principles

Typography should be:

- Clear
- Consistent
- Readable
- Accessible
- Timeless
- Calm

Avoid decorative typography that competes with the content.

---

# Typeface

Primary Typeface

PaglaAI Sans

Reasoning

PaglaAI Sans offers:

- Excellent readability
- Wide language support
- Neutral personality
- Mature rendering across platforms
- Familiarity without feeling generic

It aligns with the editorial and documentation-focused philosophy of PaglaAI.

---

# Typography Hierarchy

Every page should follow a consistent hierarchy.

```
Display

↓

Heading 1

↓

Heading 2

↓

Heading 3

↓

Heading 4

↓

Body Large

↓

Body

↓

Small Text

↓

Caption

↓

Code
```

Hierarchy should be communicated through scale and spacing rather than color.

---

# Font Weights

Recommended weights:

Light

Regular

Medium

SemiBold

Bold

Avoid unnecessary weight variations.

Use weight intentionally to create emphasis.

---

# Line Length

Comfortable reading depends on line length.

Recommended range:

50–80 characters per line

Very wide paragraphs reduce readability.

---

# Line Height

Body text should prioritize readability.

Use generous line spacing.

Dense text should never feel cramped.

Headings should remain visually compact while maintaining separation from surrounding content.

---

# Paragraph Spacing

Separate ideas using whitespace rather than indentation.

Short paragraphs improve scanning and reading comfort.

Avoid long walls of text.

---

# Alignment

Default alignment:

Left aligned.

Avoid centered paragraphs except in limited contexts such as hero sections or quotations.

---

# Emphasis

Prefer emphasis in this order:

1. Typography
2. Whitespace
3. Position
4. Color

Avoid relying solely on bold text.

Avoid excessive capitalization.

Avoid underlining except for links.

---

# Code Typography

Code should always use a monospace typeface.

Code blocks should clearly distinguish themselves from body content while remaining visually consistent with the surrounding design.

---

# Documentation

Documentation prioritizes readability over visual density.

Large technical documents should maintain:

- Comfortable spacing
- Clear heading hierarchy
- Consistent code formatting
- Predictable navigation

Readers should always know where they are within the document.

---

# Accessibility

Typography should always support accessibility.

Consider:

- Legible font sizes
- Adequate line spacing
- Sufficient contrast
- Responsive scaling
- User zoom support

Never sacrifice readability for aesthetics.

---

# Responsive Typography

Typography should scale naturally across devices.

The relationship between headings and body text should remain consistent regardless of screen size.

Avoid creating completely separate typography systems for desktop and mobile.

---

# Design Principle

Typography is the primary visual language of PaglaAI.

If hierarchy cannot be understood without color or decoration, the typography system should be improved.

Great typography makes interfaces feel effortless.
