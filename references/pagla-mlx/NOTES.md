## What was studied

- PaglaMLX README structure and the pattern it establishes for product
  communication in the ecosystem.

## Observations

- **Terminal-first hero** — the product is introduced with a live capture of
  its real output, not a marketing illustration.
- **One-line summary** — "LLM orchestration, optimized for your Mac" answers
  the purpose question before anything else.
- **Install before docs** — the quickest path to value comes first.
- **Quickstart over explanation** — a minimal working example is shown before
  concepts are explained.
- **Architecture as a diagram** — a simple box-and-arrow diagram replaces
  paragraphs.
- **Badges stay minimal** — license, runtime, platform; no noise.

## What applies to PaglaAI

- Terminal and code captures are honest, technical illustration.
- Purpose first, value next, details last (`../site/CONTENT_STRATEGY.md`).
- Diagrams communicate architecture better than prose.

## What does not apply

- Repository-badge styling as a page design system.
