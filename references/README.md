# references

Visual research library.

Screenshots, notes, and captured references that preserve context and inspiration. This folder does not influence the design system directly; it documents where ideas came from.

Each reference is kept under its source, for example:

- `apple/`
- `anthropic/`
- `cloudflare/`
- `github/`
- `openai/`

Reference material is excluded from the canonical design authority and never cited as authority in `brand/` or `design-system/`.
