# Fern — Research Notes

> Non-canonical capture. These notes document what was studied and what was
> observed. They are not authority; the canonical documents remain the source
> of truth.

---

## What was studied

- Fern API reference and documentation layouts; structure of API surfaces.

## Observations

- API references follow a consistent, predictable anatomy across endpoints.
- Navigation mirrors the API structure, so the map and the territory agree.
- Every endpoint answers the same questions: what it is, how to call it, what
  it returns.

## What applies to PaglaAI

- Consistent documentation anatomy (`../site/SITEMAP.md`).
- One structure, everywhere (`../governance/DOCUMENTATION_STYLE.md`).
- API reference as a first-class, structured surface.

## What does not apply

- Auto-generated doc styling and codegen-heavy visual treatment.
