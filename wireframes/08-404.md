# WIREFRAME — 404

> Structural only. A designed state, not an accident.

---

# Question it answers

> Where am I, and where do I go now?

---

# Layout

```
┌──────────────────────────────────────────────────────────────┐
│ HEADER                                                         │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│   (empty space — generous, centered)                          │
│                                                               │
│   h1    Page not found                                        │
│   prose The page you asked for does not exist.                │
│   │  (maxWidth body, centered, short)                        │
│                                                               │
│   [primary Button: Go to home]                                │
│   [ghost Button: Search]                                      │
│   link: View the sitemap                                      │
│                                                               │
│   │  Pagla Face — monochrome, restrained (optional)          │
│                                                               │
├──────────────────────────────────────────────────────────────┤
│ FOOTER                                                         │
└──────────────────────────────────────────────────────────────┘
```

---

# Region table

| Region | Composition | Purpose |
| --- | --- | --- |
| Header | Header | keep chrome present |
| Message | h1 + prose | explain plainly |
| Actions | Buttons + link | no dead end |
| Mark | Pagla Face (optional) | carry the brand calmly |
| Footer | Footer | full navigation |

---

# Rules

- One accurate top-level heading — "Page not found"
- Never the Pagla Face in color or motion; monochrome and still
  (`../design-system/UX_PATTERNS.md`)
- At least two forward paths; the sitemap link is always present
- No layout tricks, no 404-as-decoration

---

# Responsive notes

- Centered stack: actions below prose, sitemap link below actions
- Generous vertical whitespace is the design — never shrink it to save a fold
