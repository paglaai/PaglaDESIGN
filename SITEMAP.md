# SITEMAP

> The information architecture for the PaglaAI ecosystem.

---

# Design Philosophy

The website should communicate progressively.

Visitors should naturally move from understanding **PaglaAI** as a vision, to discovering its products, then exploring documentation, and finally engaging with the community.

Every page must have a clear purpose.

Every navigation path should feel obvious.

---

# Primary Navigation

```
Home

Products

Documentation

BrandKit

Philosophy

Blog

About
```

The primary navigation should remain small, predictable, and consistent.

Avoid adding navigation items unless they represent a major area of the ecosystem.

# Long-Term Growth

The sitemap is designed to grow without requiring structural redesign.

New products should be added under **Products**.

New documentation should remain inside **Documentation**.

The top-level navigation should remain intentionally small and stable.

---

# Design Principle

Navigation should expose only the highest level of information.

The content hierarchy should reveal complexity gradually.

Visitors should never feel overwhelmed.

The architecture should scale naturally as the PaglaAI ecosystem grows.
