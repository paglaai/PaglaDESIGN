# Mockups

Design mockups, wireframes (exploratory), and visuals used in user research and validation.

**Purpose:**
Mockups capture design decisions before implementation. They serve as reference for developers and artifacts for user testing.

**Best practices:**
- Keep mockups simple and focused
- Use design tokens for colors, spacing, typography
- Include annotations explaining rationale
- Link to the user journey and feature decision if applicable
- Archive outdated versions with dates

**Relationship to wireframes/:**
- `mockups/` — polished, high-fidelity designs
- `wireframes/` — exploratory, low-fidelity sketches (not yet committed to)
