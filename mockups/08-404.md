# MOCKUP — 404

> High-fidelity, token-referenced. A designed state, not an accident.

---

# Base

- Paper background, ink text. Vertical whitespace is intentionally generous —
  the empty space is the design.

---

# Typography

| Element | Token |
| --- | --- |
| Heading | `font.size.h1`, `font.weight.medium` |
| Message | `font.size.body`, `color.base.muted`, centered under 65ch |

---

# Composition

- Centered stack, vertically centered in the space between header and footer
  (not pasted to a fold):
  1. `h1` — "Page not found"
  2. one-sentence message
  3. primary Button — "Go to home"
  4. ghost Button — "Search"
  5. link — "View the sitemap"
- Optional: the Pagla Face, monochrome `color.base.ink`, still, no motion,
  `space.12` below the actions — restrained brand presence (D-006, D-008)

---

# Components in use

- **Button:** primary + ghost
- **Link:** descriptive anchor; sitemap link always present
- **Header/Footer:** unchanged chrome — the user is never stranded

---

# Spacing rhythm

- Heading to message `space.4`; message to actions `space.8`
- Buttons `space.2` apart, stacked below `breakpoint.small`
- Mark `space.12` below actions; `space.24` of vertical air total

---

# Dark theme

Standard inversion; Pagla Face renders in `color.base.ink`
(`#F5F5F3` on dark), still monochrome.

---

# Reduced motion

Nothing moves; the state is static by design
(`../design-system/UX_PATTERNS.md`).
